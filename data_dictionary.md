# Data Dictionary — Synthetic Sleep & Wellbeing Dataset

> **All data is SYNTHETIC / fictional.** Generated by `R/generate_data.R` with
> `set.seed(42)`. It does not describe real individuals.

## Files

| File | Description |
|------|-------------|
| `data/raw/sleep_wellbeing_raw.csv` | Raw, intentionally messy dataset (all columns stored as text). |
| `data/processed/sleep_wellbeing_clean.csv` | Cleaned, typed dataset produced by `clean_dataset()`. |

## Columns

| Column | Type (cleaned) | Valid range / levels | Description |
|--------|----------------|----------------------|-------------|
| `participant_id` | character | `P0001`…`Pnnnn` | Unique synthetic participant identifier. |
| `survey_date` | Date | 2023-01-01 … 2023-05-01 | Date the synthetic survey was "completed". |
| `age` | numeric (years) | 0–120 | Participant age. Values outside range set to `NA`. |
| `gender` | factor | Male, Female, Other | Canonicalised from messy raw labels (`M`, `male`, `F`, …). |
| `sleep_hours` | numeric (hours) | 0–24 | Average nightly sleep. Impossible values (e.g. 30, −2) set to `NA`. |
| `sleep_quality` | ordered factor | Poor < Fair < Good < Excellent | Self-reported sleep quality. |
| `caffeine_cups` | numeric (cups/day) | 0–30 | Caffeinated drinks per day. |
| `screen_time_hours` | numeric (hours/day) | 0–24 | Screen time per day. |
| `exercise_days_per_week` | numeric (days) | 0–7 | Days exercised per week. |
| `stress_level` | numeric (1–10) | 1–10 | Self-reported stress. |
| `mood` | factor | Happy, Neutral, Sad, Anxious | Self-reported dominant mood. |
| `wellbeing_score` | numeric (0–100) | 0–100 | Self-reported overall wellbeing (outcome variable). |

## Intentional data-quality issues in the RAW file

These are injected on purpose so the validation/cleaning workflow has real work
to do:

* **Missing values** — encoded as `""`, `NA`, `N/A`, `na` across several columns.
* **Duplicate rows** — ~2% of records are exact duplicates.
* **Inconsistent category labels** — e.g. `Male`/`male`/`M`/`MALE`/`Female `;
  `good`/`GOOD`/`great`/`average` for sleep quality.
* **Invalid / impossible numeric entries** — e.g. `sleep_hours = 30`, `age = 200`,
  `wellbeing_score = 150`, `exercise_days_per_week = 10`.
* **Non-numeric text in numeric fields** — e.g. `caffeine_cups = "two"`, `"3 cups"`.
* **Stray whitespace** — e.g. `"  5.2  "` in `screen_time_hours`.

## Built-in (synthetic) relationships

By construction, `wellbeing_score` increases with `sleep_hours` and
`exercise_days_per_week`, and decreases with `stress_level` and `caffeine_cups`,
plus random noise. These relationships are artefacts of the generator and are
**not** empirical findings.
